# JLZ-EDU-AG-030 Codex执行任务书

## 1. 基线

- 任务编号：`JLZ-EDU-EXPANSION-30-FULL-DELIVERY`
- 候选来源：`CAND-046`
- 正式产品：`JLZ-EDU-AG-030` / 课程顾问沟通质检
- 类型：Agent
- 批次：3
- 业务中心：14 客户洞察与渠道运营中心
- 版本基线：`EDUCATION_BASELINE_V1.0.0`
- 产品版本：`1.0.0`
- 许可证：Apache-2.0

## 2. 用户、痛点与目标

- 用户：销售主管、校区负责人、课程顾问、客服
- 痛点：销售话术培训与真实通话/聊天执行之间脱节，主管抽听成本高，难以发现事实错误、越权承诺和需求挖掘不足。
- 目标：对授权、脱敏的沟通记录按需求识别、信息真实性、异议处理、承诺边界和下一步质量做复核与辅导。

## 3. 输入契约

| 键 | 名称 | 类型 | 必填 |
|---|---|---|---|
| `conversation_transcripts_redacted` | 脱敏沟通记录 | array | 是 |
| `authorization_status` | 录制与使用授权状态 | string | 是 |
| `course_and_price` | 课程与价格 | string | 是 |
| `consultant_stage` | 沟通阶段 | string | 是 |
| `sales_policy` | 销售规范 | string | 是 |
| `prohibited_claims` | 禁用承诺 | array | 是 |
| `review_period` | 质检周期 | string | 是 |

## 4. 工作流

1. 确认授权和数据范围
2. 切分沟通结构
3. 评分与引用证据
4. 标记事实/合规风险
5. 生成一对一辅导
6. 抽样复测

## 5. 阶段状态

| 阶段 | 动作 | 退出成果 |
|---|---|---|
| S1_SCOPE_CONFIRMATION | 确认目标、校区/岗位/课程范围、期限、交付格式和可用资料。 | 任务确认单与最多3个关键缺口 |
| S2_EVIDENCE_INVENTORY | 盘点沟通转录/摘要、课程与价格、授权状态、沟通目标、顾问阶段、销售规范和禁用承诺，标记来源、版本、敏感字段与冲突。 | 证据清单、缺口表和冲突表 |
| S3_PROFESSIONAL_DIAGNOSIS | 围绕对授权、脱敏的沟通记录按需求识别、信息真实性、异议处理、承诺边界和下一步质量做复核与辅导。进行专业诊断，形成问题树和优先级。 | 问题树、风险和优先级 |
| S4_SOLUTION_DESIGN | 按确认授权和数据范围 → 切分沟通结构 → 评分与引用证据 → 标记事实/合规风险 → 生成一对一辅导 → 抽样复测设计首选方案和受限备选方案。 | 方案、责任人、完成标准 |
| S5_HUMAN_CONFIRMATION | 由销售主管/校区负责人/合规人员复核沟通事实、违规承诺、处置决定与员工沟通；不得作为唯一人事依据。 | 确认记录、未决项和升级项 |
| S6_FINAL_DELIVERY | 生成完整交付成果，执行结构、证据、安全、品牌和独立安装检查。 | 最终成果、范围限制和复盘指标 |

## 6. 核心成果

- `沟通质检报告`
- `证据片段`
- `风险承诺`

## 7. 差异化与排重

- 与现有产品：咨询话术负责生成，试听复盘看结果；本产品审查真实沟通过程的质量与风险，是销售运营质检。
- 排重检查：部分重叠；共享销售沟通对象，但输出为质检评分、证据和辅导，不是话术生成或成交复盘。
- 独立理由：只需授权后的沟通记录即可独立运行。

## 8. 安全与人工门禁

- 复核角色：销售主管/校区负责人/合规人员
- 复核范围：沟通事实、违规承诺、处置决定与员工沟通；不得作为唯一人事依据
- 不调用外部收费API。
- 不自动修改外部系统、执行退款、审批合同、处分员工或联系外部人员。
- 高风险产品完成状态必须确认人工复核。
