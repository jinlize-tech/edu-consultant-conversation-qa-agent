# 课程顾问沟通质检领域指南

## 业务问题

销售话术培训与真实通话/聊天执行之间脱节，主管抽听成本高，难以发现事实错误、越权承诺和需求挖掘不足。

## 产品解决方案

对授权、脱敏的沟通记录按需求识别、信息真实性、异议处理、承诺边界和下一步质量做复核与辅导。

## 输入质量要求

| 字段 | 名称 | 必填 | 质量要求 |
|---|---|---|---|
| `conversation_transcripts_redacted` | 脱敏沟通记录 | 是 | 仅授权范围内的真实通话或聊天转录 |
| `authorization_status` | 录制与使用授权状态 | 是 | 未获授权不得处理 |
| `course_and_price` | 课程与价格 | 是 | 真实课程和收费口径 |
| `consultant_stage` | 沟通阶段 | 是 | 线索、试听、跟进或续费 |
| `sales_policy` | 销售规范 | 是 | 允许与禁止的表达 |
| `prohibited_claims` | 禁用承诺 | 是 | 保分、升学、名额等 |
| `review_period` | 质检周期 | 是 | 抽样范围和日期 |

## 证据判断

- 用户原文优先于模型推断。
- 外部政策或公开事实应记录标题、发布机构、发布日期、URL、访问日期和适用范围。
- 无法核验时标记`EVIDENCE_UNVERIFIED`，不补造来源。
- 数据冲突必须并列展示，并说明对结论的影响。

## 人工复核

销售主管/校区负责人/合规人员应确认：沟通事实、违规承诺、处置决定与员工沟通；不得作为唯一人事依据。未经确认的内容只能作为草案。

## 主要风险

录音/聊天涉及隐私，需明确授权与脱敏；模型评分不能作为唯一人事依据；转写可能出错。
